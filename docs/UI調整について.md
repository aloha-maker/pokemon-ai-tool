# 全体
* ブラウザ上でスクロールがなくてもすべての要素が見えるようにしたい
* お互いのパーティーはゲーム画面のプレビューの下に配置する。（選出予測機能の文字は削除する）※予測を開始ボタンはそのまま

# パーティ欄
* 縦1×横6でポケモンの画像も表示するようにしたい。
* ポケモンの入力欄は画像下部に被るように配置する
* 選出されたポケモンは画像をクリックすれば識別できるようにする（枠の色を変えるなど）
* 先発かどうかもわかるようにしたい
* ポケモンの残りHPもわかるようにしたい
* HPバーはドラッグすることで調整でき、残りの割合と実数が表示されるようにする
* ポケモンの持ち物がわかるようにしたい（持ち物はユーザーが選択できる、選択時はプルダウン、表示はアイコン）
* ポケモンをクリックすると覚えている技を選択できる、技はPPをユーザーが増やしたり減らしたりできる）
