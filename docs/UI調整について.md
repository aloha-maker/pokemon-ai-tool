# 全体
* ブラウザ上でスクロールがなくてもすべての要素が見えるようにしたい
* お互いのパーティーはゲーム画面のプレビューの下に配置する。（選出予測機能の文字は削除する）※予測を開始ボタンはそのまま

# パーティ欄
* 縦1×横6でポケモンの画像も表示するようにしたい。
* ポケモンの入力欄は画像下部に被るように配置する
* 選出されたポケモンは画像をクリックすれば識別できるようにする（枠の色を変えるなど）（先発かどうかも）
  * 1回目クリック*: ポケモンを選択状態にし、画像に青い枠を表示します。
  * 2回目クリック*: 選択状態のまま、さらに先発状態にし、星アイコンを表示します。
  * 3回目クリック*: 選択と先発をすべて解除し、枠と星を非表示にします。
* ポケモンの残りHPもわかるようにしたい
* HPバーはドラッグすることで調整でき、残りの割合と実数が表示されるようにする
* HPが0になったポケモンは画像をグレースケールする
* ポケモンの持ち物を表示する
  * 持ち物はHPバーの下に名称を表示
  * 名称の左にアイコンを表示する
  * 持ち物はユーザーがプルダウンで選択できる
  * アイコンをクリックすると使ったことを示すためにグレースケールする。もう一度クリックするともとに戻す。
* ポケモンをクリックすると覚えている技を選択できる、技はPPをユーザーが増やしたり減らしたりできる）
* 相手のパーティ情報を保存できるようにしたい
* パーティ読み込みが壊れている：解決

# プレビューについて
* 解析を開始とは別にプレビュー開始するための機能をつけてほしい
* プレビューを開始するときにもとのウインドウのレイヤが下でも読み取って表示してほしい
