# F-01 対戦動画学習におけるポケモン名日本語認識の改善案

## 1. 概要

`F-01 対戦動画学習`機能において、対戦動画からポケモン名を日本語で正確に取得できていない問題への改善策を提案する。
現在のOCRによるテキスト抽出方法には限界があるため、複数のアプローチを組み合わせることで認識精度を向上させる。

## 2. 課題

- OCRによるポケモン名の誤認識（特に特殊なフォントや背景）
- 似たような文字列のポケモン名の混同
- ニックネームへの対応（スコープ外だが将来的課題）

## 3. 改善策

### 3.1. OCR精度の向上

#### 3.1.1. 画像の前処理強化

- **目的:** OCRエンジンがテキストを認識しやすいように画像を加工する。
- **手法:**
    - **二値化・閾値処理の最適化:** `cv2.threshold` の閾値を固定値ではなく、適応的閾値処理 (`cv2.adaptiveThreshold`) に変更し、様々な明るさのフレームに対応する。
    - **ノイズ除去:** メディアンフィルタ (`cv2.medianBlur`) などを適用し、動画の圧縮ノイズなどを軽減する。
    - **解像度の向上:** 超解像モデル（ESRGANなど）を用いて、文字部分の解像度を上げてからOCRを実行する。

#### 3.1.2. ポケモン名に特化したOCR学習

- **目的:** ポケモンのゲーム内フォントに特化した学習済みデータを作成し、Tesseractの認識精度を向上させる。
- **手法:**
    - ゲーム画面からポケモン名のフォント画像を収集する。
    - Tesseractの学習ツール（tesstrainなど）を用いて、収集したフォント画像でモデルを再学習（Fine-tuning）する。

### 3.2. 辞書ベースの文字列補正

- **目的:** OCR結果の軽微な誤りを、既存のポケモン名リスト（マスターデータ）を使って修正する。
- **手法:**
    - `pokemons.csv` から全ポケモン名のリストを辞書として保持する。
    - OCRで抽出した文字列と辞書内の各ポケモン名を比較し、編集距離（レーベンシュタイン距離など）を計算する。
    - 編集距離が最も近い、かつ閾値以下のポケモン名を正しい結果として採用する。
    - 例: 「リザードソ」→「リザードン」、「ギルガルド」→「ギソガレド」のような誤認識を補正。

### 3.3. 画像認識モデルの導入

- **目的:** テキスト情報（OCR）だけでなく、ポケモン自体の画像から種族を特定する。OCRとの併用で頑健性を高める。
- **手法:**
    - **ポケモン画像データセットの構築:** 公式図鑑やゲーム画面からポケモンの画像を収集し、ラベル付けする。
    - **画像分類モデルの学習:** 収集したデータセットで、CNN（Convolutional Neural Network）ベースの画像分類モデルを学習させる。
    - **推論:** OCRで名前を抽出する領域と同時に、ポケモンが表示されている領域を切り出し、学習済みモデルで種族を特定する。
    - **結果の統合:** OCRの結果と画像認識の結果を照合し、最終的なポケモン名を決定する。片方が低信頼度の場合はもう片方を採用するなど、信頼度スコアに基づいて統合する。

### 3.4. 文脈情報の活用

- **目的:** 対戦の流れやルールから、出現するポケモンの候補を絞り込む。
- **手法:**
    - **選出ポケモンの限定:** 対戦開始時の選出画面で認識した6体のポケモンリストを作成し、その対戦中に出現するポケモンはその6体に限定されるという制約を利用する。
    - **タイプ相性の利用:** 技が当たった際の効果（「こうかばつぐん」「いまひとつ」など）の表示を認識し、その結果とタイプ相性表を照らし合わせることで、ありえないポケモン候補を除外する。

## 4. 提案する実装ステップ

1.  **Step 1 (短期): 辞書ベースの補正機能の実装**
    - 最も実装コストが低く、即時的な効果が見込める。まずはOCR結果に対して編集距離による補正を導入する。
2.  **Step 2 (中期): OCR前処理の強化**
    - 適応的閾値処理やノイズ除去を導入し、OCRの入力品質を向上させる。
3.  **Step 3 (長期): 画像認識モデルの導入**
    - データセット構築とモデル学習にコストがかかるが、最も根本的な精度向上が期待できる。OCRが全く機能しないような場面（特殊なエフェクト、角度など）にも対応可能になる。

これらの改善策を段階的に導入することで、ポケモン名の認識精度を大幅に向上させることができると考えられる。
