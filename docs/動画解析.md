# ポケモンAIツール - 動画OCR処理システム 仕様書

## システム概要

本システムはポケモン対戦動画からフレームを抽出し、OCR（光学文字認識）と画像マッチング技術を用いて、各種ゲーム情報を自動的に抽出・保存するツールです。

---

## システムアーキテクチャ

### 1. コア処理フロー
```
動画入力 → フレーム抽出 → フェーズ判定 → ROI処理 → データ保存
```

### 2. 主要コンポーネント階層

#### 2.1 エントリポイント層
- **`01_ocr_text-img_from_video.py`** - メイン実行スクリプト
  - 動画ファイルの監視と処理ループ制御
  - 各プロセッサーの初期化と連携

#### 2.2 設定管理層
- **`config.py`** - システム設定集中管理
  - ディレクトリパス設定
  - ROI定義（関心領域）
  - フェーズ別ROIカテゴリ分類
  - Tesseract OCR設定

#### 2.3 動画処理層
- **`video_processor.py`** - 動画処理コア
  - フレーム抽出（指定FPSでサンプリング）
  - フェーズ管理との連携
  - 処理済み動画の管理

#### 2.4 フェーズ管理層
- **`phase_manager.py`** - ゲームフェーズ状態管理
  - フェーズ遷移: `stay` → `select` → `battle.choose` → `battle.act`
  - ROI処理状態の追跡
  - バトルフラグ管理

#### 2.5 OCR処理層
- **`ocr_processor.py`** - OCR処理コントローラー
  - フェーズ別ROI処理のルーティング
  - 各専門プロセッサーの協調制御
  - バトルID管理とポケモン名追跡

#### 2.6 プロセッサー層（専門処理）

##### 2.6.1 基本処理
- **`base_roi_processor.py`** - ROI処理基底クラス
  - ROI画像抽出・保存機能
  - テキスト保存機能
  - パス管理ユーティリティ

##### 2.6.2 OCR専門処理
- **`ocr_roi_processor.py`** - OCR専門プロセッサー
  - 画像前処理（ノイズ除去・二値化）
  - Tesseract OCR実行
  - 文字列クリーニングと補正
  - バトルIDに基づくポケモン名補正

##### 2.6.3 画像マッチング処理
- **`image_matcher.py`** - テンプレートマッチングエンジン
  - 単一/複数画像マッチング
  - 類似度スコア計算
  - 閾値ベースの判定

##### 2.6.4 画像ROI処理
- **`image_roi_processor.py`** - 画像ベースROI処理
  - 条件付き画像保存（select ROI）
  - 勝敗判定処理

##### 2.6.5 特殊ROI処理
- **`special_roi_processor.py`** - 特殊機能プロセッサー
  - HPゲージ解析
  - 状態異常アイコン判定
  - テラスタルアイコン判定

#### 2.7 外部連携層

##### 2.7.1 名前補正システム
- **`name_corrector.py`** - マスタデータ連携補正
  - ポケモン名補正（`PokemonNameCorrector`）
  - 特性名補正（`AbilityNameCorrector`）
  - 類似度閾値（0.6）による自動補正

##### 2.7.2 データベース連携
- **`db_access.py`** - データベースアクセス
  - バトルIDに紐づくポケモンリスト取得
  - SQLiteデータベース管理

##### 2.7.3 画像解析エンジン
- **`hp_ocv.py`** - HPゲージ解析
  - HSV色空間によるHP割合計算
- **`aliment_ocv.py`** - 状態異常判定
  - テンプレートマッチングによる状態異常識別
- **`tera_ocv.py`** - テラスタル判定
  - テラスタルタイプの画像認識

#### 2.8 ユーティリティ層
- **`utils.py`** - 汎用ユーティリティ
  - Windows長パス対応

## 詳細仕様

### 1. フェーズ管理システム

#### 1.1 フェーズ定義
| フェーズ | 状態 | 主要処理内容 |
|---------|------|-------------|
| `stay` | 待機中 | select ROIの検出待機 |
| `select` | 対戦選択 | 相手情報・バトルID取得 |
| `battle.choose` | バトル開始 | ポケモン名・HP・状態異常取得 |
| `battle.act` | バトル中 | 実況コメント・特性・テラスタル判定 |

#### 1.2 フェーズ遷移条件
- **stay → select**: `select` ROIの画像マッチング成功
- **select → battle**: `start`画像の検出成功
- **battle.choose → battle.act**: 自分のポケモン名のOCR失敗
- **battle.act → stay**: 勝敗画面（`win_lose`）の検出
- **battle.act → battle.choose**: 新しいポケモンの登場検出

### 2. ROI（関心領域）処理システム

#### 2.1 ROIカテゴリ分類

##### 2.1.1 フェーズ別ROI割当
```python
SELECT_ROIS = ['select', 'opponent_name', 'battle_id', 'start']
BATTLE_CHOOSE_ROIS = ['my_pokemon_name', 'my_pokemon_hp', 'my_ailment', 
                      'opponent_pokemon_name', 'opponent_pokemon_hp', 'your_ailment']
BATTLE_ACT_ROIS = ['live_comment_row1', 'live_comment_row2', 'my_tokusei_row1', 
                   'my_tokusei_row2', 'terastal', 'terastal_me', 'your_tokusei_row1', 
                   'your_tokusei_row2', 'win_lose']
```

##### 2.1.2 機能別ROI分類
- **OCR処理ROI**: ポケモン名、特性名、実況コメント等
- **画像マッチングROI**: select, start, win_lose
- **特殊処理ROI**: HP, 状態異常, テラスタル
- **条件付き保存ROI**: select ROI（閾値達成時のみ保存）

#### 2.2 処理方式別分類

| 処理方式 | 適用ROI | 使用技術 |
|----------|---------|----------|
| OCR処理 | テキスト領域 | Tesseract OCR + 前処理 |
| 画像マッチング | UI要素 | OpenCV テンプレートマッチング |
| HP解析 | HPゲージ | HSV色空間分析 |
| アイコン判定 | 状態異常・テラスタル | テンプレートマッチング |

### 3. データ補正システム

#### 3.1 名前補正機能
- **ポケモン名補正**: マスタデータとの類似度比較（閾値0.6）
- **特性名補正**: 能力マスタデータとの照合
- **コンテキスト補正**: バトルIDに紐づくポケモンリスト限定検索

#### 3.2 テキストクリーニング
- 空白・記号の統一化
- 誤字パターンの自動修正（例: 「八」→「ハ」）
- 数字形式の統一

### 4. 画像処理技術仕様

#### 4.1 前処理パイプライン
```
入力画像 → グレースケール化 → メディアンフィルタ → 大津の二値化 → OCR
```

#### 4.2 マッチング設定
- **手法**: `TM_CCOEFF_NORMED`（正規化相互相関）
- **閾値**: デフォルト0.8（設定可能）
- **アルファチャンネル対応**: 透過PNGのマスク処理

#### 4.3 HP解析技術
- **分析領域**: 画像中央1行のみ
- **色空間**: HSVによる色範囲判定
- **色範囲**: 緑・黄・赤のHPゲージ対応

## ファイル出力体系

### 1. ディレクトリ構造
```
出力ルート/
├── 動画名/
│   ├── ROI名/
│   │   ├── {ハッシュ}_{ROI名}_{フレーム番号}.png
│   │   └── {ハッシュ}_{ROI名}_{フレーム番号}.gt.txt
```

### 2. 命名規則
- **画像ファイル**: `{short_hash}_{roi_name}_{frame_idx:06d}.png`
- **テキストファイル**: `{short_hash}_{roi_name}_{frame_idx:06d}.gt.txt`
- **短縮ハッシュ**: 動画名のMD5ハッシュ先頭8文字

## 外部依存関係

### 1. 主要ライブラリ
- **OpenCV**: 画像処理・動画処理

### 3. 画像リソース
- **UIテンプレート**: select, start, win/lose画像
- **アイコンセット**: テラスタル、状態異常アイコン
- **カスタム訓練データ**: `tessdata_custom/`

## 性能特性

### 1. 処理速度
- **フレーム抽出レート**: 1秒あたり1フレーム（設定可能）
- **並列処理**: 単一動画逐次処理

### 2. 精度管理
- **OCR信頼度**: 複数指標（最大・平均・中央値）出力
- **マッチング閾値**: 設定可能な類似度閾値
- **補正閾値**: 名前補正の類似度閾値（0.6）

### 3. エラーハンドリング
- ROI範囲外検出
- テンプレート読み込み失敗
- データベース接続エラー
- 画像保存失敗
