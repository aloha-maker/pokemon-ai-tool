 P0-1: 依存関係の固定

  現状
  requirements.txt にライブラリのバージョンが一切指定されておらず、環境の再現性がなく、意図しない破壊的変更のリスクに晒されている。

  修正内容
  現在正常に動作している環境のライブラリバージョンを requirements.txt に == 形式で固定（ピンニング）する。

  手順
   1. 現在稼働している開発環境の仮想環境をアクティベートする。
   2. ターミナルで以下のコマンドを実行し、requirements.txt を上書きする。
   1     pip freeze > requirements.txt
   3. 生成された requirements.txt を開き、主要なライブラリ（Flask, opencv-pythonなど）のバージョンが Flask==2.2.2 のように固定されていることを目視で確認する。

  影響範囲
   - requirements.txt
   - プロジェクト全体のビルドおよびデプロイプロセス

  テスト方法
   1. 修正後の requirements.txt を使って、クリーンな新しい仮想環境を構築する。
   1     python -m venv new_env
   2     source new_env/bin/activate  # または new_env\Scripts\activate
   3     pip install -r requirements.txt
   2. アプリケーションを起動 (python app.py) し、クラッシュしないことを確認する。
   3. ブラウザで主要な画面（トップページ、データベース管理画面など）にアクセスし、表示が崩れたり、コンソールにエラーが出たりしないか基本的なスモークテストを行う。

  工数
  約1時間（作業自体は数分だが、クリーンな環境での動作確認を含む）

  リスク
   - リスク: 低。現在の環境にすでにライブラリ間の軽微な非互換性が存在する場合、それが固定化されるリスクはあるが、バージョン未指定の状態よりはるかに安全。
   - 対策: テスト方法に記載の通り、クリーンな環境でアプリが起動し、基本機能が動作することを確認する。
