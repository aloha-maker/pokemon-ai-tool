P0-4: パス・トラバーサルの脆弱性修正

  現状
  src/routes/api/capture.py の /api/ocr_test エンドポイントが、ユーザーからの image_path を検証せずにファイルシステムにアクセスしている。

  修正内容
  ユーザーが指定したパスを絶対パスに変換し、それが許可されたディレクトリ（例: static/captures）配下にあることを確認するチェック処理を追加する。

  手順
   1. src/routes/api/capture.py の ocr_test 関数を修正する。
       * 修正前:

   1         image_path = data['image_path']
   2         if not os.path.exists(image_path):
   3             return jsonify({"error": f"Image not found at '{image_path}'"}), 404
       * 修正後:

    1         from flask import current_app
    2         import os
    3 
    4         image_path = data['image_path']
    5 
    6         # --- バリデーション追加 ---
    7         # 基準となるディレクトリ (プロジェクトルート/static/captures)
    8         base_dir = os.path.abspath(os.path.join(current_app.root_path, '..', 'static', 'captures'))
    9         # ユーザー指定パスを絶対パスに変換
   10         user_abs_path = os.path.abspath(os.path.join(base_dir, image_path))
   11 
   12         # ユーザーのパスが基準ディレクトリ配下にあるかチェック
   13         if not user_abs_path.startswith(base_dir):
   14             return jsonify({"error": "不正なファイルパスです。"}), 400
   15 
   16         if not os.path.exists(user_abs_path):
   17             return jsonify({"error": f"Image not found at '{image_path}'"}), 404
   18 
   19         # 以降は user_abs_path を使用
   20         img = cv2.imread(user_abs_path)
   21         # ...

  影響範囲
   - src/routes/api/capture.py

  テスト方法
   1. 正常系: image_path に some_image.png のような、static/captures 内に存在するファイル名を指定してAPIを呼び出し、正常にOCRが実行されることを確認する。
   2. 異常系（トラバーサル攻撃）: image_path に ../../app.py のようなディレクトリを遡るパスを指定してAPIを呼び出す。
   3. 確認: サーバーが 400 Bad Request と {"error": "不正なファイルパスです。"} を返し、app.py を読み込もうとしないことを確認する。

  工数
  約1時間（修正箇所が限定的で、テストも容易なため）

  リスク
   - リスク: 低。修正は自己完結しており、他の機能への影響はない。
   - 対策: 正常系・異常系の両方のテストを必ず実施する。
