# F-08 詳細設計書: AI行動予測機能

## 1. 概要

本機能は、OCR機能によって抽出された現在のゲーム状態（盤面情報）を入力として受け取り、次に取るべき行動（技の選択など）をAIモデルが予測し、推奨事項として提示することを目的とする。

## 2. 責任範囲

- 現在の盤面情報（自ポケモンの状態、相手ポケモンの状態など）を解析する。
- データベースに保存されているポケモン図鑑や技データを参照し、盤面情報のテキストを補完・構造化する。
- 構造化されたデータに基づき、AIモデルが最適な行動を推論する。
- 推論結果（推奨する行動と、その理由）を整形して返す。

## 3. 主要コンポーネント

### 3.1. `ActionAIModel` クラス (`src/ai/predictor.py`)

行動予測AIのロジックをカプセル化するクラス。

#### 主要メソッド

- **`__init__(self)`**
  - **機能:** `ActionAIModel` のインスタンスを初期化する。
  - **処理:**
    1. `DatabaseManager` のインスタンスを生成し、データベースへの接続を準備する。

- **`predict_action(self, game_state: dict) -> dict`**
  - **機能:** 現在のゲーム状態から、推奨される行動を予測する。
  - **引数:**
    - `game_state` (dict): `GameStateParser` から得られた盤面情報の辞書。
  - **戻り値:** 推奨行動とその理由を含む辞書 (例: `{'action': '１０まんボルト', 'reason': '相手のギャラドスに効果抜群のため'}`)
  - **処理:**
    1. `game_state` から自ポケモン名 (`my_pokemon_name`) と相手ポケモン名 (`opponent_pokemon_name`) を取得する。
    2. `DatabaseManager` を通じて、それぞれのポケモンの詳細データ（タイプなど）をデータベースから取得する。
    3. `_calculate_type_advantage()` を呼び出し、タイプ相性を計算する。
    4. 相性計算の結果や、その他の戦術的判断（例: HPの状況）に基づき、最も効果的な行動を決定する。
    5. 決定した行動と、その選択理由をまとめた辞書を生成して返す。

- **`_calculate_type_advantage(self, my_pokemon_types: list, opponent_pokemon_types: list, move_type: str) -> float`**
  - **機能:** 技のタイプと相手ポケモンのタイプの相性倍率を計算する。
  - **引数:**
    - `my_pokemon_types` (list): 攻撃側ポケモンのタイプリスト。
    - `opponent_pokemon_types` (list): 防御側ポケモンのタイプリスト。
    - `move_type` (str): 使用する技のタイプ。
  - **戻り値:** 相性倍率 (例: `4.0`, `2.0`, `1.0`, `0.5`, `0.25`, `0.0`)。
  - **処理:**
    1. `src/core/type_chart.py` に定義されたタイプ相性表を参照する。
    2. 技のタイプが、相手ポケモンの各タイプに対してどの程度の倍率になるかを計算する。
    3. (オプション) 攻撃側ポケモンのタイプと技のタイプが一致する場合の「タイプ一致ボーナス」を考慮する。
    4. 最終的なダメージ倍率を返す。

## 4. データフロー

1. **入力:**
   - `GameStateParser` が生成したゲーム状態の辞書 (`dict`)。

2. **処理:**
   - `app.py` の `handle_get_suggestion` イベントハンドラが `ActionAIModel` をインスタンス化し、`predict_action()` を呼び出す。
   - `ActionAIModel` が `DatabaseManager` を使って、推論に必要な補足情報（ポケモンのタイプなど）を取得する。
   - 内部ロジック（現在は主にタイプ相性）に基づき、最適な行動を判断する。

3. **出力:**
   - 推奨行動と理由を含む辞書 (`dict`)。
   - この辞書はSocketIOを通じてクライアントに送信される。

## 5. 依存関係

- **外部ライブラリ:**
  - なし

- **内部モジュール:**
  - `src.core.ocr.GameStateParser`: AIへの入力データとなる盤面情報を提供。
  - `src.database.manager.DatabaseManager`: ポケモンや技の詳細データを取得するために利用。
  - `src.core.type_chart`: タイプ相性の計算ロジックで参照。

## 6. 今後の拡張性

現在の `ActionAIModel` は、主にタイプ相性に基づいたシンプルなルールベースAIである。将来的には以下の要素を考慮することで、より高度な推論が可能になる。

- **HPの状況:** 自分や相手の残りHPに応じて、攻撃技と補助技の選択を切り替える。
- **場の状態:** 「ステルスロック」や「天候」などの影響を考慮する。
- **過去の行動ログ:** 過去の対戦データから、特定の状況で成功／失敗した行動を学習する（機械学習モデルの導入）。
- **相手の持ち物や特性の推測:** 行動パターンから相手の状態を推測し、判断材料に加える。
