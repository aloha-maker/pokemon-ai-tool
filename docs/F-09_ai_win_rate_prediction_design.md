# F-09 詳細設計書: AI勝率予測機能

## 1. 概要

本機能は、自軍のパーティ構成と相手のパーティ構成（見せ合い画面を想定）を入力として受け取り、データベースに蓄積された過去の対戦履歴やポケモンの相性に基づいて、自軍の選出（3体）と、その選出での勝率を予測・提示することを目的とする。

## 2. 責任範囲

- ユーザーが入力した自パーティのポケモン6体と、相手パーティのポケモン6体のリストを受け取る。
- `DatabaseManager` を通じて、各ポケモンの詳細データ（タイプ、種族値など）を取得する。
- 自パーティから3体を選出する全ての組み合わせ（6C3 = 20通り）を生成する。
- 各選出パターンについて、相手パーティ全体との相性を評価し、スコアを計算する。
- 最もスコアが高い（有利と判断される）選出パターンを「最適選出」として特定する。
- 最適選出の勝率を予測し、その根拠と共に返す。

## 3. 主要コンポーネント

### 3.1. `WinRatePredictor` クラス (`src/ai/win_rate_predictor.py`)

パーティ選出と勝率予測のロジックをカプセル化するクラス。

#### 主要メソッド

- **`__init__(self)`**
  - **機能:** `WinRatePredictor` のインスタンスを初期化する。
  - **処理:**
    1. `DatabaseManager` のインスタンスを生成し、データベースへの接続を準備する。

- **`predict_best_team(self, my_party_names: list[str], opponent_party_names: list[str]) -> dict`**
  - **機能:** 最適な選出と予想勝率を計算する。
  - **引数:**
    - `my_party_names` (list[str]): 自パーティのポケモン名リスト（6体）。
    - `opponent_party_names` (list[str]): 相手パーティのポケモン名リスト（6体）。
  - **戻り値:** 最適選出、勝率、評価理由などを含む辞書。
  - **処理:**
    1. `DatabaseManager` を使って、入力された全12体のポケモンの詳細データを取得する。
    2. `itertools.combinations` を使って、自パーティから3体を選出する全ての組み合わせを生成する。
    3. 各組み合わせについて `_calculate_team_score()` を呼び出し、相手パーティに対する有利度をスコアリングする。
    4. 最もスコアの高かった組み合わせを「最適選出」とする。
    5. `_predict_win_rate()` を呼び出し、最適選出の勝率を予測する。
    6. 結果をまとめた辞書を返す。

- **`_calculate_team_score(self, my_selection: list[dict], opponent_party: list[dict]) -> float`**
  - **機能:** ある選出（3体）が、相手パーティ（6体）に対してどれだけ有利かを数値化する。
  - **引数:**
    - `my_selection` (list[dict]): 選出された自ポケモン3体のデータリスト。
    - `opponent_party` (list[dict]): 相手パーティ6体のデータリスト。
  - **戻り値:** 有利度を表すスコア (float)。
  - **処理:**
    1. 選出された3体それぞれについて、相手の6体それぞれとのタイプ相性を計算する。
    2. 有利な相性（効果抜群）にはプラスのスコア、不利な相性（効果いまひとつ、効果なし）にはマイナスのスコアを与える。
    3. 全ての組み合わせのスコアを合計し、チーム全体のスコアとして返す。

- **`_predict_win_rate(self, best_team_score: float) -> float`**
  - **機能:** チームスコアを基に、具体的な勝率（%）を予測する。
  - **戻り値:** 予想勝率 (float)。
  - **処理:**
    1. （現状の簡易ロジック）スコアを特定の計算式（例: シグモイド関数など）に入れ、0%から100%の範囲の数値に変換する。
    2. （将来的には）過去の対戦ログから、「スコア」と「実際の勝敗」の関係を学習した回帰モデルを用いて、より精度の高い勝率を予測する。

## 4. データフロー

1. **入力:**
   - 自パーティのポケモン名リスト (6体)
   - 相手パーティのポケモン名リスト (6体)
   - (Web UIの `/predict` エンドポイント経由でJSONとして渡される)

2. **処理:**
   - `app.py` がリクエストを受け取り、`WinRatePredictor` をインスタンス化して `predict_best_team()` を呼び出す。
   - `WinRatePredictor` が `DatabaseManager` を利用してポケモンデータを取得し、内部ロジックに基づいてスコアリングと勝率予測を行う。

3. **出力:**
   - 最適選出、予想勝率、理由を含む辞書 (`dict`)。
   - この辞書はJSONとしてクライアントに返される。

## 5. 依存関係

- **外部ライブラリ:**
  - `itertools`: パーティの組み合わせを生成するために使用。

- **内部モジュール:**
  - `src.database.manager.DatabaseManager`: ポケモンデータを取得するために利用。
  - `src.core.type_chart`: スコアリング時の相性計算で参照。
