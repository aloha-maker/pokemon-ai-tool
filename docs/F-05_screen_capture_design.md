# F-05 詳細設計書: 画面キャプチャ機能

## 1. 概要

本機能は、指定されたアプリケーションウィンドウの画面をキャプチャし、画像データとして後続の処理（OCRなど）に提供することを目的とする。リアルタイムでのゲーム画面解析の基礎となる重要なモジュールである。

## 2. 責任範囲

- 指定されたウィンドウ名に一致するウィンドウを探索し、そのハンドルを取得する。
- 対象ウィンドウの全体または指定された領域をキャプチャし、OpenCVの画像オブジェクト（`numpy.ndarray`）として返す。
- ウィンドウが見つからない、またはキャプチャに失敗した場合に、エラーハンドリングを行う。

## 3. 主要コンポーネント

### 3.1. `ScreenCapturer` クラス (`src/core/capture.py`)

画面キャプチャ処理全体をカプセル化するクラス。

#### 主要メソッド

- **`__init__(self, window_title: str)`**
  - **機能:** `ScreenCapturer` のインスタンスを初期化する。
  - **引数:**
    - `window_title` (str): キャプチャ対象のウィンドウのタイトル。
  - **処理:**
    1. `window_title` をインスタンス変数に保存する。
    2. `_find_window()` を呼び出して、ウィンドウハンドルを探索・保存する。

- **`_find_window(self) -> bool`**
  - **機能:** `window_title` に一致するウィンドウを探し、そのハンドルを取得する。
  - **戻り値:** ウィンドウが見つかった場合は `True`、見つからなかった場合は `False`。
  - **処理:**
    1. `pygetwindow.getWindowsWithTitle()` を使用して、指定されたタイトルを持つウィンドウを検索する。
    2. ウィンドウが見つかれば、そのハンドルをインスタンス変数 `self.window` に保存し、`True` を返す。
    3. 見つからなければ `False` を返す。

- **`capture_frame(self, region: tuple = None) -> np.ndarray | None`**
  - **機能:** 対象ウィンドウのスクリーンショットを取得する。
  - **引数:**
    - `region` (tuple, optional): `(x, y, width, height)` の形式で指定するキャプチャ領域。指定されない場合はウィンドウ全体をキャプチャする。
  - **戻り値:**
    - 成功した場合: キャプチャした画像データ (`numpy.ndarray`)。
    - 失敗した場合: `None`。
  - **処理:**
    1. ウィンドウハンドル (`self.window`) が有効か確認する。
    2. `PIL.ImageGrab.grab()` を使用して、ウィンドウの領域 (`bbox`) を指定してスクリーンショットを取得する。
    3. 取得した画像を `RGB` から `BGR` 形式に変換する（OpenCVで扱えるようにするため）。
    4. `region` が指定されている場合は、画像を指定された領域で切り抜く。
    5. 最終的な画像データを返す。エラーが発生した場合は `None` を返す。

## 4. データフロー

1. **入力:**
   - キャプチャ対象のウィンドウタイトル (例: "ポケットモンスター スカーレット")
   - (オプション) キャプチャする領域 `(x, y, w, h)`

2. **処理:**
   - `ScreenCapturer` が `pygetwindow` を使ってウィンドウを特定する。
   - `PIL` (Pillow) を使って画面をキャプチャする。
   - `OpenCV` と `NumPy` を使って画像を適切な形式に変換・加工する。

3. **出力:**
   - `BGR` 形式の画像データ (`numpy.ndarray`)

## 5. 依存関係

- **外部ライブラリ:**
  - `pygetwindow`: ウィンドウの特定とジオメトリ情報の取得。
  - `Pillow` (`PIL`): 画面のキャプチャ。
  - `OpenCV` (`cv2`): 画像のフォーマット変換と加工。
  - `NumPy`: 画像データの配列操作。

- **内部モジュール:**
  - なし (本モジュールはコア機能であり、他モジュールに依存しない)

## 6. エラーハンドリング

- **ウィンドウが見つからない場合:**
  - `_find_window` が `False` を返し、`capture_frame` は `None` を返す。
  - 呼び出し元の `ocr_and_suggestion_thread` (`app.py`) などで、ユーザーへの通知（SocketIO経由）やスレッドの停止処理が行われる。
- **キャプチャに失敗した場合:**
  - `capture_frame` 内の `try-except` ブロックで例外が捕捉され、コンソールにエラーが出力された後、`None` が返される。
