 全体構成

   * アプリケーションエントリポイント: app.pyがFlaskアプリケーションの起動と設定（Application Factoryパターン）を担当しています。
   * フロントエンド: templatesディレクトリにあるHTMLファイル（index.htmlなど）をsrc/routes/views.pyがレンダリングして表示します。
   * バックエンドAPI: src/routes/api/ディレクトリ以下のファイル群が、機能ごとに分割されたRESTful APIを提供します。
   * リアルタイム通信: src/sockets/handlers.pyで定義されたSocket.IOハンドラが、リアルタイムな双方向通信を実現します。
   * 動画ストリーミング: src/routes/streaming.pyが、OpenCVでキャプチャした画面やカメラ映像をWebページにストリーミング配信します。
   * データベース: src/database/manager.pyがSQLiteデータベースとの接続やCRUD操作をカプセル化し、各APIから利用されています。
   * AI機能: src/ai/ディレクトリに、パーティ生成や勝率予測などのAIロジックが実装されています。
   * 画像認識(OCR): src/core/ocr/ディレクトリに、OpenCVとTesseract OCRを利用してゲーム画面から情報を抽出する機能が実装されています。

  主要機能とルーティング一覧

  1. Webページ表示 (UI)
  src/routes/views.pyで定義されています。
   * GET /: メインページ (index.html) を表示します。
   * GET /database: データベースビューアページ (database_viewer.html) を表示します。

  2. AIによる分析・提案
  src/routes/api/ai.pyで定義されています。

   * POST /api/ai/predict: 現在の自分と相手のパーティ情報から、選出するべきポケモンと勝率を予測します。
   * POST /api/ai/generate-party: 指定したコンセプトに基づき、AIが新しいパーティを生成します。

  3. 対戦履歴・ログ管理
  src/routes/api/battle.pyで定義されています。

   * GET /api/history: これまでの対戦履歴と統計情報を取得します。
   * POST /api/history/add: 対戦ログを追加します。
   * POST /api/battles/save_result_with_log: OCRで読み取ったイベントログと共に対戦結果を保存します。
   * GET /api/battle/new_id: 新しい対戦IDを生成します。

  4. 画面キャプチャとOCR
  src/routes/api/capture.pyで定義されています。

   * GET /api/windows: 現在開かれているウィンドウの一覧を取得します。
   * POST /api/capture: 指定したウィンドウのスクリーンショットを撮影します。
   * POST /api/ocr_test: 画像ファイルパスを指定してOCR処理を実行し、結果をJSONで返します。
   * POST /api/party/recognize_opponent: 画面から相手のパーティを認識します。

  5. 動画の非同期解析
  src/routes/api/video.pyで定義されています。

   * POST /api/videos/upload: 対戦動画をアップロードし、バックグラウンドで非同期に解析タスクを開始します。
   * GET /api/videos/status/<task_id>: 動画解析タスクの進捗状況（待機中、処理中、完了、エラー）を確認します。
   * GET /api/videos/result/<log_id>: 解析完了後、結果（対戦ログ）を取得します。

  6. パーティ管理 (CRUD)
  src/routes/api/party.pyで定義されています。

   * GET /api/parties: 登録されているパーティの一覧を取得します。
   * POST /api/parties: 新しいパーティを登録します。
   * GET, PUT, DELETE /api/parties/<party_id>: 特定のパーティの取得、更新、削除を行います。
   * POST /api/register-generated-party: AIが生成したパーティを育成済みポケモンとパーティの両方に一括登録します。

  7. 育成済みポケモン管理 (CRUD)
  src/routes/api/trained_pokemon.pyで定義されています。

   * GET /api/trained-pokemons: 育成済みポケモンの一覧を取得します。
   * POST /api/trained-pokemons: 新しい育成済みポケモンを登録します。
   * GET, PUT, DELETE /api/trained-pokemons/<pokemon_id>: 特定の育成済みポケモンの取得、更新、削除を行います。

  8. マスターデータ提供
  src/routes/api/master.pyで定義されています。

   * GET /api/master/pokemons: ポケモンマスタの全データを取得します。
   * GET /api/master/moves, /items, /abilities など: 各種マスタデータを取得します。

  9. データベース操作
  src/routes/api/database.pyで定義されています。

   * GET /api/db/tables: データベース内の全テーブル名を取得します。
   * GET /api/db/search: 指定したテーブル内のデータをキーワードで検索します。

  10. 映像ストリーミング
  src/routes/streaming.pyで定義されています。

   * GET /video_feed: 指定したウィンドウの映像をリアルタイムでストリーミングします。
   * GET /camera_feed: PCに接続されたカメラの映像をストリーミングします。

  11. その他
   * 分析ダッシュボード (`dashboard.py`): 対戦データに基づいた様々な統計情報（使用率、勝率など）を提供します。
   * ROI設定 (`roi.py`): OCRで読み取る画面上の領域(Region of Interest)を設定・保存します。
