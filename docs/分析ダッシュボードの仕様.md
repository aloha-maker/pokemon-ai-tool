# 分析ダッシュボード仕様書

## 1. 概要
データベースに記録された対戦ログを集計・可視化し、ユーザーが自身の強み・弱みを分析し、戦略を改善するためのインサイトを提供するダッシュボード機能。

## 2. データソース
以下のテーブルからデータを集計して表示する。
- `battles`: 対戦ごとの基本情報（勝敗、ランク、日時）
- `parties`: 対戦ごとのパーティ構成と選出情報
- `pokemons`: 相手ポケモンの詳細情報（技、持ち物、テラスタイプなど）

## 3. 表示項目
ダッシュボードは、以下の分析項目をカード形式で表示する。

### 3.1. サマリー
対戦全体のパフォーマンスを概観する。
- **全体勝率**: 全期間の勝率、勝敗数を表示 (例: `62% (80勝50敗)`)
- **シーズン勝率**: 現在のレギュレーションやシーズンにおける勝率、勝敗数を表示。
- **ランク推移**: `battles`テーブルの`my_rank`と`battle_date`を元に、ランクの変動を折れ線グラフで可視化する。

### 3.2. ポケモン別分析
特定のポケモンに対する戦績を分析する。
- **遭遇率が高い相手ポケモン (TOP 10)**: `parties`テーブルを集計し、相手パーティに含まれていたポケモンの出現回数ランキングを表示。
- **要注意ポケモン (勝率が低い相手 TOP 5)**: 遭遇時の勝率が著しく低い相手ポケモンをリストアップし、それぞれの勝率と対戦回数を表示。
- **得意なポケモン (勝率が高い相手 TOP 5)**: 遭遇時の勝率が高い相手ポケモンをリストアップし、同様に勝率と対戦回数を表示。

### 3.3. 選出分析
自分の選出傾向と、その結果を分析する。
- **自分のポケモンの選出率**: `parties`テーブルを集計し、自分のパーティ内での各ポケモンの選出率（選出回数 / パーティにいた回数）をランキング表示。
- **選出パターン別勝率**: 自分が選出した3体の組み合わせごとに、その選出パターンでの勝率を算出して表示。

### 3.4. 環境・メタ分析
相手のポケモンの構成や傾向を分析する。
- **人気カスタマイズランキング**:
    - ユーザーが分析したい相手ポケモンを一人選択する。
    - 選択されたポケモンに対し、`pokemons`テーブルを集計し、最も多く使われている**技構成**、**持ち物**、**テラスタイプ**の組み合わせをランキング形式で表示する。
    - これにより、環境に多いポケモンの「型」を把握できる。

## 4. UI/UX
- 要件定義書にある「近未来的デザイン」を継承し、Bootstrap 5とカスタムCSSでグラスモーフィズムやネオン効果を取り入れる。
- 各分析項目は独立したカードコンポーネントとして配置する。
- グラフ描画には `Chart.js` などのJavaScriptライブラリの利用を想定する。
- 各カードには「詳細」ボタンを設け、クリックすると関連する対戦ログの一覧をモーダルウィンドウで表示する。
