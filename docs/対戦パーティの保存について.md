# 対戦パーティの保存について
* 選出予測欄にあるポケモンや持ち物などのすべての情報を保存する機能を追加したいです。
* 予測を開始ボタンの左に新たに「パーティ保存ボタン」を追加して、このボタンを押下するとこの機能が実行されるようにする。
* ボタンを押下するとポップアップで勝敗の選択ができて、その勝敗情報も保存できるようにする。
* 保存した情報は分析ダッシュボードで確認できるようにする。

 現状では、ポップアップで「勝利」または「敗北」を選択すると、コンソールにログを出力し、アラートを表示するまでを実装しています。次のステップでは、実際にパーティの全情報をデータベースに保存する処理を実装します。
